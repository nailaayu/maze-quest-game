# MAZE QUEST GAME

## Bahasa Indonesia

Game petualangan labirin berbasis web yang dikembangkan menggunakan HTML, CSS, dan JavaScript. Pemain harus menjelajahi labirin dan mengumpulkan koin.

### Fitur
- Gameplay labirin interaktif
- Sistem pengumpulan koin
- Tampilan responsif

### Teknologi
HTML, CSS, dan JavaScript.

### Cara Menjalankan
Buka file `loading.html` menggunakan browser.

---

## English

A web-based maze adventure game developed using HTML, CSS, and JavaScript. Players must explore the maze and collect coins.

### Features
- Interactive maze gameplay
- Coin collection system
- Responsive display

### Technologies
HTML, CSS, and JavaScript.

### How to Run
Open the `loading.html` file in a browser.
